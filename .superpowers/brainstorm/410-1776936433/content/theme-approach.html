配色主题策略

现有主题系统如何与新布局融合？

LumiTerm — Catppuccin Mocha
❯ PS
… output …
~/projects ❯
cmd
LumiTerm — Tokyo Night
❯ PS
… output …
~/projects ❯
cmd

A · 保留现有 5 个主题

Catppuccin Mocha、Dracula、Tokyo Night、Nord、Latte 原样保留，只把新 Warp 布局套进去。主题切换器不变。

LumiTerm — Warp Dark ✨ new
❯ PS
… output …
~/projects ❯
cmd
LumiTerm — Catppuccin Mocha（仍可用）
~/projects ❯
cmd

B · 加入 Warp Dark 主题（推荐）

新增一个"Warp Dark"主题（#1c1c1e 深黑调），设为默认。原来的 5 个主题照常保留，用户可自由切换。

LumiTerm — Warp Dark
❯ PS
… output …
~/projects ❯
cmd
（主题切换器移除）

C · 全换 Warp Dark，移除主题切换

彻底换成 Warp 风格配色，删掉主题切换器，减少维护复杂度。

推荐 B：向后兼容，已有主题不丢失，Warp Dark 作为新默认体验最流畅。
