点击 ⚙ 从右侧滑出，终端区域收窄。三个分类（主题/字体/快捷键）左侧导航切换。

B · 居中模态框（推荐）

背景变暗，居中弹出设置对话框。左侧导航切换分类，右侧显示内容。ESC 或点击背景关闭。最像 Warp/VS Code 的体验。

C · 扩展现有下拉菜单

现有 ⚙ 齿轮菜单基础上扩展，点击分类进入二级面板。改动最小，但内容多时会很局促。

推荐 B · 居中模态框，空间充裕、体验现代，和 Warp/VS Code 的设置风格最一致。
