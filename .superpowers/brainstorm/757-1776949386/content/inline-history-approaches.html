内联历史列表：两种实现方式

效果相同，技术路径不同——选择更适合你的

方案 D — 原生 Shell（PSReadLine）
E:\claudecode\lumi-term
PS> git status
nothing to commit
[#]> cd ▌
<-/10> <History(10)>
> cd E:\claudecode\lumi-term\ [History]
> cd e:\ [History]
> cd .\lumi-term\ [History]
> cd E:\claudecode\ [History]
> cd d:\desktop\lumi-term [History]
如何工作
在 PowerShell 配置文件里设置 PSReadLine，Shell 自己渲染历史列表（ANSI 序列），LumiTerm 只负责传递键盘输入和显示输出
✓ 完全在 xterm 内，最原生
✓ Tab 补全等所有 Shell 功能保留
✗ 仅限 PowerShell，CMD/WSL 需单独配置
✗ LumiTerm 的 frecency 历史不参与排序

如何工作
InputBar 内嵌在终端底部（方案 B），输入时自动在下方显示 HTML 历史列表，无需 Ctrl+R
✓ PowerShell / CMD / WSL 均支持
✓ Frecency 排序算法保留
✓ 输入即过滤，默认 10 条
✗ 历史列表是 HTML 层，不在 xterm 内
