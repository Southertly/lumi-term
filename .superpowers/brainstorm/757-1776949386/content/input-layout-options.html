↑↓ 历史

A — 现状：底部独立输入框

xterm 只显示输出，输入框是独立 HTML 元素，视觉上分离

E:\claudecode
PS E:\claudecode> git status
On branch main
nothing to commit
~/claudecode | main
❯ git commit -m "▌

B — Warp 风格：输入内嵌终端内部

xterm 占满全部高度，输入行用绝对定位覆盖在终端底部，视觉上像在终端内输入

E:\claudecode
PS E:\claudecode> git status
On branch main
nothing to commit
PS E:\claudecode > git commit -m "▌

C — 纯原生终端模式

移除 InputBar，键盘直接输入 xterm（传统终端方式）。Shell 自己渲染提示符，失去 frecency 历史记录功能

推荐：方案 B — 保留 frecency 历史和 CWD 显示的同时，给你「在终端内输入」的体验。方案 C 最简单但失去了已有的 InputBar 功能。
